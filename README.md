# Agentic Robotics @ CVPR 2027

Website for the **Agentic Robotics: Towards General-Purpose Embodied Intelligence** workshop at CVPR 2027.

Live site: https://agenticrobotics.github.io

Single-file static site. Edit `index.html` and push to `main`; GitHub Pages redeploys automatically.

Peter Stone's avatar uses `images/people/peter-zoomout.png`, a square portrait with the original dark studio background extended using the built-in imagegen tool. It shows the full head, shoulders, and upper torso with space around the person, using the same circular crop as the other speakers. Keep the original public portrait at `images/people/peter.png` for provenance; do not restore the oversized CSS crop or render the original rectangle as an inset inside the circle.
